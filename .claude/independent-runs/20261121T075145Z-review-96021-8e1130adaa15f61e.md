## Verdict

## Findings

### Minor

**1. The balance-envelope parse is now duplicated — two callers, one shape** `src/unlimited/adapters/mimo.py:211-219` vs `src/unlimited/adapters/deepseek.py:20-27`

The extraction in this commit stopped one line short: only the *amount* parse (`decimal`) moved to `schema`, while the `balance_infos` envelope (`first dict entry`, `currency`, `enabled=is_available is True`, `credits(...)` with `used=None, limit=None`) is now byte-for-byte duplicated across two adapters, differing only in the field name (`total_available` vs `total_balance`) and the `why` word (`vendor-error` vs `no-limits`). This is the second real caller the project's convention says to extract on: a `balance_reading(vendor, account, now, ans, field, *, why)` helper (in `schema.py` or a shared adapter module) would own the fetch-failed → `failed()`, the no-amount → `unread`, and the envelope walk in one place. Contained, and both adapters' suites (`tests/test_mimo.py:226`, `tests/test_sources.py:599`) cover the result, so the author can verify the applied change. `[apply-direct]`

**2. `schema.decimal`'s numeric-string and non-string branches are only covered indirectly** `src/unlimited/schema.py:24-29`

The new shared helper is exercised through `_balance` (`"10.00"` → `10.0`, `"lots"` → `None`) and through DeepSeek (`"12.50"`, `"n/a"`), which is honest coverage of the two branches that matter. The plain-number passthrough is untested — as it was when the same line lived in `deepseek._amount`, so this is not a regression, just a gap a one-line case in `tests/test_sources.py:DeepSeek` would close for the shared function. Optional. `[apply-direct]`

**3. The `Balance.BODY` fixture's components don't reconcile with the vendor's own formula** `tests/test_mimo.py:229-231`

`cash 8.50 + gift 2.00 + credit_available 0.00 ≠ total_available 10.00`, and `frozen 0.50` reconciles with neither. Harmless because only `total_available` is asserted and the other keys are unused decoration — but the fixture reads like a captured sample, so a future reader will use it as one. Either make the components sum or drop the unused ones. `[apply-direct]`
